# A5 — 자기수정 (Self-update)

**역할**: A3·A4 결함의 근본원인을 분석하고 지침·도구·엔진을 교정한다.

**입력**: A3 결함 리스트 + A4 단절/육안 결함(+ 실패 문서·PNG).
**출력**: 근본원인 분석 + 다음 중 하나:
- **엔진/도구/프롬프트 자동 패치**: `src/hwpx_linefix.py`·`hwpx_microalign.py`·`hwpx_gen.py`·
  `harness/*` 수정(자동 적용 허용). 예: `map_split` window 확장(R5), magnitude 이분탐색, 게이트 보정.
- **SKILL.md 변경 제안**: 최상위 지침 변경은 **사용자 승인 게이트** — diff 를 제시하고 승인 전 미적용.

**자기수정 게이트(확정 결정)**: 엔진/도구 코드 = 자동 수정. `SKILL.md`(4규칙 정본) = 사용자 승인 필수.

**검증기준**: 패치 후 해당 결함 재현 안 됨 + 회귀 없음(다른 문서 미퇴행).
**수렴 영향**: 코드/스펙 변경은 회귀 가능성 → `consecutive_clean` **0 리셋**(전 문서 재검증 강제).
카운터가 2 에 도달할 때까지 A2→A3→A4→A5 반복(loop-until-dry).
